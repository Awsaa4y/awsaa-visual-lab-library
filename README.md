# مكتبة أوسع للبيكتوجرام — مخبر الوسائل البصرية

مكتبة رموز بصرية (بيكتوجرام) بديلة لمكتبة مخبر الوسائل البصرية في مدرسة أوسع المنزلية،
مشتقة من مجموعة **Mulberry Symbols** (CC BY-SA 4.0 — تسمح بالاستخدام التجاري مع النسبة).

- **العدد الإجمالي:** 206 صورة PNG (500×500، خلفية شفافة)
- **الفئات:** routine (روتين يومي) × 65 — home (أنشطة منزلية) × 49 — outdoor (أنشطة خارجية) × 52 — emotions (مشاعر وتواصل) × 40
- **الفهرس:** `manifest.json` — لكل ملف: المسار، التسمية العربية، الفئة، الكلمة الإنجليزية، الملف المصدر.
- **الترخيص:** انظر `ATTRIBUTION.md` — النسبة إلزامية، والمشتقات بنفس الرخصة (CC BY-SA 4.0).
- **الفجوات:** بعض المفاهيم لا يوجد لها رمز مطابق في المجموعة — مسجلة في تقرير البناء.
